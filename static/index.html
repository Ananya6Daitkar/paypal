THE INTENT RECEIPT / METHOD

A promise in.
A verified order out.

  1. You describe the purchase. Your own words become the reference for the review.
  2. AI checks for mismatch. It can explain concerns, but cannot edit the cart, choose the price, or authorize money.
  3. PayPal's order is checked again. The server retrieves the approved order and compares merchant, amount, currency, and line items with the reviewed snapshot before capture.
  4. You make the final call. If the check fails, capture is blocked. Sandbox transactions use test money only.

Offline preview mode is labeled and cannot unlock payment.
